H3 asks which diagnostic best predicts when a model breaks on situations that are related to its training but shifted. Something has to define “breaks”, and it had to be defined before any diagnostic score existed. That is the fragility suite: frozen on 6 October with the tag fragility-v1.

About minutes · Files: src/fragility/othello.py, src/docs/fragility_suite.md, src/tests/test_othello_fragility.py

14.1Same rules, shifted situations

Every variant keeps the Othello rules exactly as they are and changes only which positions the model is asked about, so the right answer always comes from othello.py. Nothing in the suite retrains or adapts the model. The proposal had listed “altered legal move rules” too, but a model can only follow a changed rule after being adapted to it, and adaptation is what D3 measures; using it here would make H3 partly “does D3 predict D3”. The team dropped it on 5 October, before freezing the suite.

14.2Symmetry: the same game, relabelled

For a random-game model this is barely a shift, because random games open in all four directions equally. For a championship model it is a real one: the archive records every game in one orientation, so all 110,005 of its training games open with F5 (Lesson 4), and a rotated game starts with a move it has never seen first.

14.3After a pass

A position counts when the next recorded move is made by the same player who made this one: the opponent had to pass. A model that only learned “the players take turns” proposes a move for the wrong player there. Passes are not that rare (about a third of random games and 58% of championship games contain one), but they are a small share of positions.

14.4Detours: pushing the model off its line

  • 194–195One forward pass for every game still alive, reading only the last position’s probabilities.
  • 197–203Passes and game ends follow the rules: no legal move means a pass, and if neither player can move the game is over, and counts as completed.
  • 205–209An illegal top move ends that game as a failure.
  • 212–218With probability p, and only when there is a choice, the move is swapped: for a random other legal move, or for the one the model gives the lowest probability.

14.5One number per model

  • 271Every static variant’s drop: the in-distribution legal move rate minus the variant’s.
  • 279–283Every detour drop: the undisturbed completion rate (p = 0) minus the completion rate with detours, for each mode and each p.
  • 291fragility = the mean of all the drops. Higher means more fragile. The drops are kept one by one too, so H2 can ask which shifts each diagnostic sees.
A drop needs something to drop from

An untrained model scores a fragility near zero (0.02 to 0.03 in a smoke run): it is equally bad everywhere and has nothing to lose. That is why the in-distribution rate is always reported next to fragility, why H3 uses only admitted models, and why Amendment 1 divides fragility by the in-distribution rate (relative fragility) before asking which diagnostic predicts it (Lesson 8).

14.6Frozen, and how to run it

Everything the suite does is set by one dictionary, SUITE (1,000 test games per variant, data seed 0, the symmetries, the detour settings), and suite_hash() hashes it together with the version name. The freeze test in Lesson 8 fails if the hash ever differs from 644671bfb322. A different suite has to be a new version with a new tag, and every result file records which suite and hash produced it.

python src/fragility/othello.py --model outputs/zoo/othello_transformer_small_synthetic_s0/model.pt \
    --arch transformer --scale small --train_distribution synthetic --seed 0
# writes results/fragility/othello_transformer_small_synthetic_s0.json:
#   in_distribution_legal_rate, legal_rate per variant, detour results, drops, fragility, suite_version, suite_hash

The tests check the suite against two models whose answers are known: a perfect world model (replays the rules, proposes only legal moves) must score zero on every variant, and a broken one (always the same square) must fail. They also check that each symmetry keeps the start board, that the after-pass positions are real passes, and that the same seed gives the same detours.
