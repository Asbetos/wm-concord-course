D1 asks whether each proposed move is legal. D2 asks something D1 cannot: does the model treat two histories that reach the same board the same way, and two histories that reach different boards differently, exactly where the boards differ? It is the state-equivalence test of Vafa et al. (2024), and this lesson takes it apart line by line.

11.1The idea: what a state is

In Othello, once you know the board and whose turn it is, the history no longer matters: every possible future is decided. The Myhill–Nerode theorem says the same thing for any system with a finite set of states (a deterministic finite automaton): two histories are the same state exactly when every continuation is equally allowed after both. A model with a real world model should respect that in both directions.

  • Compression.Two histories that reach the same state should get the same answer from the model. If they don’t, the model is still reacting to how it got there.
  • Distinction.Two histories that reach different states should get different answers, on exactly the moves that differ. If they don’t, the model has merged two boards.

11.2What the model “accepts”

A model outputs scores, not a set of moves, so D2 needs a rule for which moves the model accepts after a history h. It uses no threshold at all: if k moves are truly legal after h, the model’s accepted set A(h) is its k highest-scoring squares. The model gets exactly as many picks as there are legal moves, so nothing has to be tuned, and a perfect model’s picks are exactly the legal set.

11.3The two errors, worked by hand

Compression · same state pair

D3 C3 C4 and C4 C3 D3: legal C5, E3 after both, so k = 2. A hypothetical model accepts:

A(h)C5E3
A(g)C5F3

Accepted after only one of the two: E3 and F3, out of the 3 moves accepted after either.

compression error = |A(h) △ A(g)| ÷ |A(h) ∪ A(g)| = 2 ÷ 3

Distinction · different state pair

E6 D6 C5 (legal B4, F4, B6, F6) and F5 D6 C6 (legal F4, B6, F6). The boundary is B4: legal after the first only. A hypothetical model accepts:

A(h)B4F4B6F6
A(g)B4F4F6

B4 is accepted after both, so the model has not separated the boards where they differ.

distinction error = boundary moves not separated ÷ boundary moves = 1 ÷ 1

A boundary move that is legal only after h counts as separated when the model accepts it after h and not after g, and the mirror holds for moves legal only after g. Both errors are averaged over their pairs, and the score keeps the project’s rule that higher is better:

score = 1 − ( mean compression error + mean distinction error ) / 2

11.4Histories: every prefix, with its true state

  • 100–104Who moves next? legal_next() returns the other player’s moves if there are any, otherwise the mover’s own (Lesson 3). So whether its first square is legal for the other player tells which list it is, and therefore whether the other player has to pass.
  • 111Replay all games with legal moves (Lesson 3).
  • 114–123Every prefix of every game is a history. Positions with no legal move (game over) are left out, and a prefix shared by several games, such as a common opening, is kept once: a pair of identical move sequences says nothing about state equivalence.
  • 124–129The true state is the board plus the player to move, packed into bytes so that two equal states compare equal as dictionary keys.

11.5Sampling the pairs

All possible pairs are far too many to score, so both errors are estimated from samples: up to 2,000 pairs of each kind, drawn with seed 0. The pairs depend only on the games, never on the model, so every model of a distribution is judged on exactly the same pairs.

  • 143–147Same-state pairs: group the histories by state, then list every pair inside each group. These come from move orders that can be swapped, which is rarer than it sounds.
  • 149–151If there are more than 2,000, keep a uniform random sample of 2,000.
  • 162–166Different-state pairs are matched on length: a history length is drawn in proportion to how many pairs it offers, so every possible same-length pair is equally likely.
  • 169–176Draw two histories of that length, and draw again if their legal sets are equal or the pair was already taken.

11.6Accepted sets and the errors in code

  • 190–194One forward pass per game gives the scores for every prefix at once, because the models are causal: position t only sees moves 0 to t. Token 0 (padding) is dropped from the scores.
  • 195–199Ranking with argsort twice gives every square its rank; a square is accepted when its rank is below k, the number of legal moves. That is the top-k rule for all histories in one vectorized step.
  • 203–206Compression error per pair: moves accepted after exactly one history (^, exclusive or) over moves accepted after either (|).
  • 209–218Distinction error per pair: the boundary moves, legal after exactly one history, and the share of them the model fails to separate.
  • 264–273Same-state pairs occur only where move orders can be swapped, so 1,000 games may not give enough. If there are fewer than 500, add 1,000 test games at a time, up to 5,000. The synthetic anchor needed 4,000 games; the championship anchor 2,000.
  • 261–263, 275The prepared histories and pairs are cached per distribution, so scoring 27 models of one distribution replays the games once.

11.7Why both errors are needed

The tests run three fake models whose answers are known in advance. Their scores show what each error catches:

Fake modelCompression errorDistinction errorScore
Oracle: accepts exactly the legal moves of the true board0.0000.0001.000
Constant: always accepts the same squares, ignoring the history0.0000.9690.516
Noise: a random answer for every exact move sequence0.9260.8680.103

The constant model is the reason for the second error. It never treats two histories of the same board differently, because it treats everything the same, so its compression is perfect. Only the distinction error reveals that it cannot tell any boards apart.

11.8The anchors, and how sure the numbers are

AnchorCompression error (pairs)Distinction error (pairs)Score
Othello-GPT synthetic0.000 (615)0.001 (2,000)0.9994
Othello-GPT championship0.145 (768)0.322 (2,000)0.7663

The synthetic Othello-GPT behaves almost exactly like the rules. The championship one, with a D1 of 0.90, merges a third of the board pairs it should tell apart: a sign that a good legal move rate can hide a weaker state model, which is the whole reason D2 exists.

Each error is a mean over pairs of a number between 0 and 1, so its standard error is at most 0.5 ÷ √n, whatever the model: at most 0.022 at the 500-pair minimum and 0.011 at 2,000. Measured on the anchors it was at most 0.005. A D2 score is known to about ±0.01, well below the differences between models that H1 compares (Amendment 2, D).

11.9Limits, and the toy check

  • Compression is measured early.Same-state pairs come from transpositions, which happen mostly in the first moves. The pair lengths are saved in every result so this can be checked per model.
  • Next move only.Vafa et al. (2024) also test longer continuations. D2 uses the next move only, which keeps it cheap enough for 81 models per domain and uses the same ground truth as the other diagnostics. The paper states this limitation.

python src/diagnostics/d2/toy_check.py --model untrained  # a tiny untrained model, runs on any laptop

toy_check.py finds the shortest same-state pair and the different-state pair with the smallest boundary in 1,000 random games, prints both boards side by side with the truly legal moves and the moves the model accepts, and computes each pair’s error. It is the five-minute live demo of D2, and it refuses zoo models, since protocols may only be tried on the anchors.
